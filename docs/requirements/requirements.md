# 자동차 관리 CRUD 프로젝트 요구사항 정의서

## 1. 프로젝트 개요

이 프로젝트는 Express REST API와 React 화면을 연결해 자동차 정보를 관리하는 풀스택 CRUD 실습 프로젝트입니다.

백엔드는 Express로 자동차 데이터 API를 제공하고, 프론트엔드는 Vite 기반 React 화면에서 API를 호출해 자동차 목록 조회, 추가, 수정, 삭제 기능을 실행합니다. 화면은 Tailwind CSS를 사용해 관리자 UI 형태로 구성합니다.

## 2. 프로젝트 목적

| 목적 | 설명 |
| --- | --- |
| REST API 구조 이해 | HTTP Method와 URL 경로를 이용한 API 구조를 익힙니다. |
| React에서 API 호출 이해 | React 컴포넌트에서 fetch를 사용해 백엔드 API를 호출하는 흐름을 익힙니다. |
| CRUD 기능 구현 연습 | 목록 조회, 추가, 수정, 삭제 기능을 직접 구현합니다. |
| 프론트엔드와 백엔드 연동 경험 | Vite proxy와 API 요청 구조를 통해 React와 Express를 연결합니다. |
| Tailwind CSS UI 구성 경험 | Tailwind CSS를 사용해 관리자 화면 스타일을 구성합니다. |
| Render 배포 및 GitHub Actions CI 경험 | Render 배포 구조와 GitHub Actions 기반 빌드 검증 흐름을 경험합니다. |

## 3. 사용자

| 사용자 | 설명 |
| --- | --- |
| 자동차 정보를 관리하는 관리자 | 자동차 정보를 화면에서 조회하고 추가, 수정, 삭제할 수 있는 사용자입니다. |
| CRUD 실습을 진행하는 학습자 | Express, React, API 연동, 배포 흐름을 학습하는 사용자입니다. |

## 4. 주요 기능 요구사항

| 기능 | 설명 |
| --- | --- |
| 자동차 목록 조회 | 등록된 자동차 목록을 테이블 형태로 확인할 수 있어야 합니다. |
| 자동차 상세 조회 | API를 통해 특정 ID의 자동차 정보를 조회할 수 있어야 합니다. |
| 자동차 추가 | 자동차 이름, 제조사, 연식, 가격을 입력해 새 자동차를 추가할 수 있어야 합니다. |
| 자동차 수정 | 기존 자동차 정보를 선택해 입력 폼에서 수정할 수 있어야 합니다. |
| 자동차 삭제 | 선택한 자동차 정보를 목록에서 삭제할 수 있어야 합니다. |
| API 상태 확인 | 서버 상태를 확인할 수 있는 health check API를 제공해야 합니다. |

## 5. 화면 요구사항

| 화면 요소 | 요구사항 |
| --- | --- |

## 6. API 요구사항

| Method | Endpoint | 역할 |
| --- | --- | --- |
| GET | `/health` | 서버 상태를 확인합니다. |
| GET | `/cars` | 자동차 목록 전체를 조회합니다. |
| GET | `/cars/:id` | 특정 ID의 자동차 정보를 조회합니다. |
| POST | `/cars` | 새 자동차 정보를 추가합니다. |
| PUT | `/cars/:id` | 특정 ID의 자동차 정보를 수정합니다. |
| DELETE | `/cars/:id` | 특정 ID의 자동차 정보를 삭제합니다. |

## 7. 데이터 구조

자동차 데이터는 다음 필드를 사용합니다.

본 프로젝트는 데이터베이스를 사용하지 않고, Express 서버의 메모리 배열에 자동차 데이터를 저장합니다. 서버를 재시작하면 데이터는 초기 상태로 돌아갑니다.

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `_id` | Number | 자동차를 구분하는 고유 ID입니다. |
| `name` | String | 자동차 이름입니다. |
| `company` | String | 자동차 제조사입니다. |
| `year` | Number | 자동차 연식입니다. |
| `price` | Number | 자동차 가격입니다. |

예시 데이터:

```json
{
  "_id": 1,
  "name": "Sonata",
  "company": "Hyundai",
  "year": 2023,
  "price": 32000000
}
```
